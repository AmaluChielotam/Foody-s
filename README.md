# Foodys — Campus Delivery Homepage

A responsive Foodys homepage concept built with React, TypeScript, Vite, Tailwind CSS v4 and Framer Motion.

## Run locally

1. Install Node.js (LTS).
2. Extract this folder and open it in VS Code.
3. In the terminal, run:

   ```bash
   npm install
   npm run dev
   ```

4. Open the localhost URL printed by Vite.

## Build for production

```bash
npm run build
npm run preview
```

## Included in this design pass

- Non-fixed floating pill navigation with responsive mobile menu.
- Large, playful Nunito typography with red-led Foodys colours.
- Hero slider with an automatically typing phrase (café, hostel, lecture break and study session).
- Redesigned four-step process cards with hover lift and glow.
- New “Why students choose Foodys” card section.
- Vertically aligned download artwork and app-store buttons on desktop.
- Playful, animated FAQ accordion with larger question and answer typography.
- More spacious newsletter and footer sections.
